# 常见问题

## 安装前需要装什么依赖吗？

普通用户不需要提前安装 Node.js、Electron 或 Mihomo。安装包已经包含运行所需文件。

## Mihomo 是这个项目自己写的吗？

不是。Mihomo 是第三方开源网络核心，本项目使用它来实现 TUN 分流、规则路由和连接信息读取。ProcessProxy Desk 主要提供 Windows 桌面界面、配置生成、进程规则管理和流量展示。

分发包含 Mihomo 的安装包时，需要说明 Mihomo 的来源、版本和许可证。详见 [Mihomo 核心说明](MIHOMO.md)。

## 为什么需要管理员权限？

真实分流使用 TUN 模式，需要创建虚拟网络接口并调整路由，这些操作在 Windows 上需要管理员权限。

## 能不能按完整路径匹配进程？

当前版本使用 Mihomo 的 `PROCESS-NAME` 规则，按 exe 文件名匹配，不按完整路径匹配。

这意味着同名 exe 即使来自不同目录，也会命中同一条规则。界面会尽量区分不同路径的运行进程，但底层规则仍按进程名生效。

## 为什么有的进程显示为直连 / 未使用代理？

可能原因：

- 进程没有命中代理规则。
- 规则被禁用。
- 进程策略设置为直连。
- 连接本身由系统或其他服务发起，不属于已配置进程。

## 累计流量从什么时候开始算？

从本次真实分流内核启动后开始累计。停止真实分流后，下一次启动会重新开始统计。

## 为什么流量监控里的进程和任务管理器不完全一致？

流量监控来自 Mihomo 当前连接数据，主要显示产生网络连接的进程。任务管理器显示的是系统全部进程，两者来源不同。

## 安装包能选择安装路径吗？

可以。当前 NSIS 安装包已经改为安装向导模式，并允许选择安装目录。

## 默认菜单栏为什么不见了？

默认的 Electron 菜单栏与应用界面风格不一致，因此已隐藏。常用功能都放在应用顶部导航和按钮中。
