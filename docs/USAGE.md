# 使用指南

## 1. 配置代理节点

打开“代理节点”页面，添加或编辑代理：

- 名称：用于在规则中识别节点。
- 类型：HTTP、HTTPS 或 SOCKS5。
- 主机：代理服务器地址。
- 端口：代理服务器端口。
- 用户名 / 密码：如果代理需要认证则填写。
- 启用：只有启用的节点会用于规则。

## 2. 添加进程规则

打开“进程规则”页面，可以通过两种方式添加规则：

- 从“运行进程”树中点击某个 exe。
- 点击“规则”按钮手动输入 exe 文件名。

规则字段说明：

- 进程名：例如 `chrome.exe`。
- 策略：走代理、直连、阻断。
- 代理节点：策略为“走代理”时选择使用哪个节点。
- 备注：可选，用来记录规则用途。

当前规则按 exe 文件名匹配。同名 exe 的不同 PID 会共用同一条规则。

## 3. 保存并应用

修改代理节点或进程规则后，点击右上角“保存并应用”。这个按钮会做两件事：

- 保存当前界面配置。
- 生成 Mihomo 内核使用的配置和规则文件。

## 4. 启动真实分流

点击顶部“启动真实分流”。程序会请求管理员权限，并启动内置 Mihomo TUN 分流。

启动后，符合规则的进程会按配置走代理、直连或阻断。

## 5. 查看流量监控

打开“流量监控”页面，可以查看：

- 总下行 / 上行累计流量。
- 代理下行 / 上行累计流量。
- 直连下行 / 上行累计流量。
- 实时总速率。
- 已使用代理的进程。
- 直连 / 未使用代理的进程。

累计流量从本次真实分流启动后开始统计。停止内核后会重新开始下一轮统计。

## 6. 诊断问题

打开“设置与诊断”或点击顶部“运行诊断”，可以检查：

- 是否具备管理员权限。
- 内置 Mihomo 核心是否存在。
- 代理节点是否有效。
- 规则是否可生成。

如果真实分流启动失败，优先查看诊断结果。
