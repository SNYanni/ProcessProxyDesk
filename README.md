# ProcessProxyDesk
一个面向 Windows 的进程级代理分流桌面工具，基于 Mihomo TUN 支持为不同应用进程配置不同 HTTP / HTTPS / SOCKS5 代理，并提供规则管理、代理节点配置、诊断和流量监控。Windows desktop app for routing different application processes through different HTTP/HTTPS/SOCKS5 proxies using Mihomo TUN, with process rules, proxy profiles, diagnostics, and traffic monitoring.
